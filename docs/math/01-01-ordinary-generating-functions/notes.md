## 1. 通常型母関数の定義

整数列 $`(a_n)_{n\ge 0}`$の**通常型母関数**（ordinary generating function; OGF）を

```math
A(x)=\sum_{n=0}^{\infty}a_nx^n
```

と定義する。$`[x^n]A(x)=a_n`$ は $`x^n`$ の係数を表す。

形式的冪級数として考えると、$`A(x)`$ は係数列そのものを表し、$`x`$ に数値を代入する必要はない。二つの形式的冪級数が等しいとは、すべての次数の係数が一致することをいう。

## 2. 数え上げと係数：硬貨の問題（Q1・Q2）

100円硬貨を最大2枚、50円硬貨を最大2枚、10円硬貨を最大3枚使い、160円を払う方法を数える。同額硬貨と順序は区別しない。使用枚数を $`(a,b,c)`$ とすれば

```math
100a+50b+10c=160,\quad 0\le a\le2,\ 0\le b\le2,\ 0\le c\le3.
```

$`100a\le160`$ より $`a\in\{0,1\}`$。$`a=0`$ では $`5b+c=16`$ で、$`b=0,1,2`$ に対して $`c=16,11,6`$ となり不適。$`a=1`$ では $`5b+c=6`$ で、$`b=0,1,2`$ のうち $`b=1,c=1`$ のみ適する。よって **1通り**。

10円を1単位とすると

```math
F(x)=(1+x^{10}+x^{20})(1+x^5+x^{10})(1+x+x^2+x^3).
```

**係数による証明：** 積を分配法則で展開する際、各因子からそれぞれ $`x^{10a},x^{5b},x^c`$ を選ぶことと、制約を満たす三つ組 $`(a,b,c)`$ を選ぶことは一対一に対応する。その積は $`x^{10a+5b+c}`$ である。したがって $`[x^{16}]F(x)`$ は160円の払い方の個数であり、上の列挙より $`[x^{16}]F(x)=1`$。□

## 3. 等比級数と収束（Q3）

$`a_n=2^n`$ の通常型母関数は

```math
A(x)=\sum_{n=0}^{\infty}2^nx^n=\sum_{n=0}^{\infty}(2x)^n.
```

**解析的な証明：** $`S_N=\sum_{n=0}^{N}(2x)^n`$ と置く。$`x\ne\frac12`$ のとき、差を取ると

```math
(1-2x)S_N=1-(2x)^{N+1},\qquad S_N=\frac{1-(2x)^{N+1}}{1-2x}.
```

$`|x|<\frac12`$ なら $`|2x|<1`$ なので $`(2x)^{N+1}\to0`$。従って

```math
\sum_{n=0}^{\infty}2^nx^n=\frac1{1-2x}\quad (|x|<\tfrac12).
```

この証明は数値としての無限級数の収束を使う。以下の形式的な議論とは区別する。

## 4. 形式的冪級数としての等比級数（Q4）

**命題：** 整数係数の形式的冪級数として、$`A(x)=\sum_{n\ge0}2^nx^n`$ とすると $`(1-2x)A(x)=1`$。

**証明：** 積の定数項は $`1`$。任意の $`n\ge1`$ で $`x^n`$ の係数は $`2^n-2\cdot2^{n-1}=0`$。よってすべての次数で右辺 $`1`$ と係数が一致する。□

同様に $`G(x)=\sum_{n\ge0}x^n`$ は $`(1-x)G(x)=1`$ を満たす。$`(1-x)G(x)=1`$ が係数ごとに成立するため、$`G(x)`$ を $`(1-x)^{-1}`$ と書ける。これは数値代入による収束を主張しない。

## 5. コーシー積（Q5）

**定理：** $`A(x)=\sum_{n\ge0}a_nx^n`$、$`B(x)=\sum_{n\ge0}b_nx^n`$ に対し、形式的冪級数の積は

```math
A(x)B(x)=\sum_{n=0}^{\infty}\left(\sum_{k=0}^{n}a_kb_{n-k}\right)x^n.
```

**証明：** 任意の $`m\ge0`$ を固定する。$`A`$ の項 $`a_ix^i`$ と $`B`$ の項 $`b_jx^j`$ の積は $`a_ib_jx^{i+j}`$。$`x^m`$ に寄与するのは $`i+j=m`$ かつ $`i,j\ge0`$ を満たす $`(i,j)=(0,m),(1,m-1),\ldots,(m,0)`$ の $`m+1`$ 組のみ。したがって $`[x^m](AB)=\sum_{i=0}^m a_ib_{m-i}`$。各係数は有限和で定義でき、収束や無限和の交換は不要。任意の $`m`$ について成立するから主張が従う。□

## 6. 基本公式 $`1/(1-x)^2`$（Q6）

$`G(x)=\sum_{n\ge0}x^n=(1-x)^{-1}`$ とする。コーシー積より

```math
[x^n]G(x)^2=\sum_{k=0}^n 1\cdot1=n+1.
```

よって形式的冪級数として

```math
\boxed{\frac1{(1-x)^2}=\sum_{n=0}^{\infty}(n+1)x^n}.
```

## 7. 3色のボールと重複組合せ（Q7）

赤・青・緑のボールを各色無制限に選び、合計 $`n`$ 個選ぶ方法を $`a_n`$ とする。各色の個数を $`(r,s,t)`$ とすると $`r+s+t=n`$、$`r,s,t\ge0`$ である。選び方と三つ組は一対一に対応するので

```math
A(x)=\left(\sum_{n\ge0}x^n\right)^3=\frac1{(1-x)^3}.
```

**証明1（コーシー積）：**

```math
A(x)=\left(\sum_{k\ge0}(k+1)x^k\right)\left(\sum_{j\ge0}x^j\right).
```

よって

```math
a_n=[x^n]A(x)=\sum_{k=0}^n(k+1)=\frac{(n+1)(n+2)}2.
```

**証明2（差分・漸化式）：** $`(1-x)A(x)=(1-x)^{-2}=\sum_{n\ge0}(n+1)x^n`$。一方、

```math
(1-x)A(x)=a_0+\sum_{n\ge1}(a_n-a_{n-1})x^n.
```

係数比較から $`a_0=1`$、$`a_n-a_{n-1}=n+1`$（$`n\ge1`$）。したがって

```math
a_n=a_0+\sum_{k=1}^n(k+1)=\sum_{k=0}^n(k+1)=\frac{(n+1)(n+2)}2.
```

どちらもすべての $`n\ge0`$ で成立する。□

## 8. 制約付き三つ組の総合問題（Q8）

$`N_n`$ を $`a+b+c=n`$、$`a,c\ge0`$、$`0\le b\le2`$ を満たす整数三つ組の個数とする。

```math
F(x)=\sum_{n\ge0}N_nx^n=\frac{1+x+x^2}{(1-x)^2}.
```

**証明（係数比較と帰納法）：**

```math
(1-2x+x^2)F(x)=1+x+x^2.
```

定数項、一次項、二次項を比較すると

```math
N_0=1,\quad N_1-2N_0=1,\quad N_2-2N_1+N_0=1,
```

したがって $`N_0=1,N_1=3,N_2=6`$。$`n\ge3`$ の係数比較から

```math
N_n=2N_{n-1}-N_{n-2}.
```

$`n\ge1`$ で $`N_n=3n`$ を示す。基底 $`n=1,2`$ は成立。$`n\ge2`$ で $`N_n=3n`$ および $`N_{n-1}=3(n-1)`$ を仮定すると

```math
N_{n+1}=2N_n-N_{n-1}=6n-3(n-1)=3(n+1).
```

よって数学的帰納法により $`N_n=3n`$（$`n\ge1`$）。$`N_0=1`$ は別扱いであり、結論は

```math
\boxed{N_n=\begin{cases}1&(n=0),\\3n&(n\ge1).\end{cases}}
```

□

**別の検算：** $`b\in\{0,1,2\}`$ を固定すると、$`a+c=n-b`$ の非負整数解は $`n-b+1`$ 個（$`n\ge b`$）。ゆえに $`N_n=\sum_{b=0}^{\min(2,n)}(n-b+1)`$。$`n=0`$ では1、$`n=1`$ では3、$`n\ge2`$ では $`(n+1)+n+(n-1)=3n`$ となり一致する。

## 9. 今回の数学的な接続

- **組合せ論：** 選択肢を多項式・冪級数に符号化し、積の係数で選び方を数える。
- **代数学への接続：** 今回は整数係数の形式的冪級数の具体的な係数演算と積を扱った。可換環の公理や一般的な逆元の存在定理は未学習。
- **離散差分：** $`(1-x)A(x)`$ の係数は $`a_0`$ と $`a_n-a_{n-1}`$。母関数の代数操作から漸化式が得られる。
- **確率論への予告：** 非負整数値確率変数の確率母関数では係数が確率となり、独立和と積が対応する。
- **フーリエ解析への予告：** 収束を伴う冪級数の評価や係数抽出を通じて複素解析・フーリエ的手法につながる。

## 10. 学習上の注意

- 方程式を満たす候補でも、枚数などの**制約をすべて確認**する。
- 場合分けでは、取り得る値の範囲を先に示して**網羅性を証明**する。
- 低次の例は一般公式の証明ではない。任意の次数 $`n`$ を固定して論じる。
- 解析的な無限級数の等式と、形式的冪級数としての等式を混同しない。
- 漸化式による帰納法では、必要な初期値と帰納法の適用範囲を明示する。
