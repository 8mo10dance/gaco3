## Q1：硬貨による160円の支払い

### 問題
100円硬貨2枚、50円硬貨2枚、10円硬貨3枚から、所持枚数以内でちょうど160円を支払う方法は何通りか。同額の硬貨と支払う順序は区別しない。使用枚数をそれぞれ $`a,b,c`$ とし、全ての可能性を数え尽くしたことも説明せよ。

### 解答
条件は

```math
100a+50b+10c=160,\qquad 0\le a\le2,\quad0\le b\le2,\quad0\le c\le3.
```

$`100a\le160`$ より $`a=0,1`$ に限られる。

- $`a=0`$：$`5b+c=16`$。$`b=0,1,2`$ に対し $`c=16,11,6`$ となり、いずれも $`c\le3`$ を満たさない。
- $`a=1`$：$`5b+c=6`$。$`b=0,1,2`$ に対し $`c=6,1,-4`$ となり、$`b=1,c=1`$ だけが適合する。

したがって $`(a,b,c)=(1,1,1)`$ の **1通り**。$`a`$ と $`b`$ の許される値を全て調べたので列挙は尽くされている。□

**学習記録：** 初回は枚数制限を見落として6通りとした。再提出で制約を確認した。添削途中に「2通り」と誤判定した箇所があったが、正しい結論は1通り。

## Q2：硬貨問題を多項式に翻訳する

### 問題
10円を1単位とし、100円硬貨に対応する $`A(x)=1+x^{10}+x^{20}`$ を与える。50円硬貨と10円硬貨の多項式 $`B(x),C(x)`$ を求め、$`F(x)=A(x)B(x)C(x)`$ の $`x^{16}`$ の係数が160円の支払い方法の数になる理由を説明せよ。

### 解答

```math
B(x)=1+x^5+x^{10},\qquad C(x)=1+x+x^2+x^3.
```

積の分配法則による各項は、許された使用枚数 $`(a,b,c)`$ に一対一に対応し、$`x^{10a+5b+c}`$ となる。したがって $`x^{16}`$ の係数は $`10a+5b+c=16`$ を満たす組の数である。Q1より

```math
[x^{16}]F(x)=1.
```

各組が係数1の項を1つ作り、同じ指数の項が足し合わされるため、この対応は重複も漏れもない。□

## Q3：数列 $`2^n`$ の通常型母関数

### 問題
$`a_n=2^n\ (n\ge0)`$ とする。(1) 通常型母関数を無限級数で表せ。(2) 分数式で表せ。(3) $`|x|<1/2`$ における等式を、収束を明示して証明せよ。

### 解答
(1) $`A(x)=\sum_{n=0}^{\infty}2^nx^n=\sum_{n=0}^{\infty}(2x)^n`$。

(2) $`|x|<1/2`$ で $`A(x)=1/(1-2x)`$。

(3) 有限和 $`S_N=\sum_{n=0}^N(2x)^n`$ を考える。$`S_N-2xS_N=1-(2x)^{N+1}`$ より、$`x\ne1/2`$ のとき

```math
S_N=\frac{1-(2x)^{N+1}}{1-2x}.
```

$`|x|<1/2`$ なら $`|2x|<1`$ なので $`(2x)^{N+1}\to0`$。従って

```math
A(x)=\lim_{N\to\infty}S_N=\frac1{1-2x}.
```

□

**追加課題：** 初回解答では収束条件を述べたが、有限和から極限への導出を省略した。再提出で有限等比和を導出した。

## Q4：収束を使わない形式的冪級数の計算

### 問題
$`A(x)=\sum_{n=0}^{\infty}2^nx^n`$ に対して、$`(1-2x)A(x)=1`$ を収束・極限を用いずに証明せよ。

### 解答
$`(1-2x)A(x)=\sum_{n\ge0}c_nx^n`$ とおく。定数項は $`c_0=1`$。任意の $`n\ge1`$ について

```math
c_n=2^n-2\cdot2^{n-1}=0.
```

よって係数列は $`(1,0,0,\ldots)`$ となり、$`(1-2x)A(x)=1`$。各係数の計算は有限回の加減乗算で完結し、収束は不要である。□

**学習記録：** 提出解答は和の添字をずらして相殺する方法。添削ではその操作を係数ごとの等式として正当化した。

## Q5：コーシー積

### 問題
$`A(x)=\sum_{n\ge0}a_nx^n`$、$`B(x)=\sum_{n\ge0}b_nx^n`$ に対して

```math
A(x)B(x)=\sum_{n\ge0}\left(\sum_{k=0}^na_kb_{n-k}\right)x^n
```

を形式的冪級数として証明せよ。指数の加法、$`x^n`$ に寄与する添字、有限和になる理由を明確にせよ。

### 解答
$`a_ix^i`$ と $`b_jx^j`$ の積は $`a_ib_jx^{i+j}`$。任意の $`n\ge0`$ を固定すると、$`x^n`$ に寄与する必要十分条件は $`i+j=n`$ である。非負整数の組は

```math
(i,j)=(0,n),(1,n-1),\ldots,(n,0)
```

の $`n+1`$ 個に限られる。従って

```math
[x^n](A(x)B(x))=\sum_{i=0}^na_ib_{n-i}.
```

任意の次数について有限和で係数が決まるので、収束を仮定せず積を扱える。□

**学習記録：** 提出時は低次の展開から一般式を導いた。添削で任意の次数の添字条件を明記した。

## Q6：$`1/(1-x)^2`$ の係数

### 問題
$`a_n=b_n=1\ (n\ge0)`$ とし、母関数を $`A(x),B(x)`$ とする。(1) 両者を分数式で表せ。(2) コーシー積から $`[x^n](AB)=n+1`$ を証明せよ。(3) 形式的冪級数の等式 $`1/(1-x)^2=\sum_{n\ge0}(n+1)x^n`$ を導け。

### 解答
(1) $`A(x)=B(x)=\sum_{n\ge0}x^n=1/(1-x)`$。ここで $`1/(1-x)`$ は $`(1-x)\sum_{n\ge0}x^n=1`$ の略記である。

(2) コーシー積より

```math
[x^n](AB)=\sum_{k=0}^na_kb_{n-k}=\sum_{k=0}^n1=n+1.
```

(3) $`AB=1/(1-x)^2`$ であり、全次数の係数が $`n+1`$ だから

```math
\frac1{(1-x)^2}=\sum_{n=0}^{\infty}(n+1)x^n.
```

□

## Q7：3色のボールの重複組合せ

### 問題
赤・青・緑の3種類のボールを各色何個でも選べる。同色のボールと順序を区別せず、合計 $`n`$ 個を選ぶ方法の数を $`a_n`$ とする。(1) 通常型母関数を求めよ。(2) $`A(x)=1/(1-x)^3`$ を説明せよ。(3) コーシー積で $`a_n=(n+1)(n+2)/2`$ を証明せよ。

### 解答（指定されたコーシー積による方法）
各色から $`r,s,t\ge0`$ 個選ぶ選択は $`x^r,x^s,x^t`$ に対応する。従って

```math
A(x)=\left(\sum_{m\ge0}x^m\right)^3=\frac1{(1-x)^3}.
```

係数 $`[x^n]A(x)`$ は $`r+s+t=n`$ を満たす組の数である。Q6の結果から

```math
A(x)=\left(\sum_{k\ge0}(k+1)x^k\right)\left(\sum_{j\ge0}x^j\right).
```

コーシー積により

```math
a_n=\sum_{k=0}^n(k+1)\cdot1=\frac{(n+1)(n+2)}2.
```

□

### 別解（実際の初回提出で採用した漸化式による方法）

```math
(1-x)A(x)=\frac1{(1-x)^2}=\sum_{n\ge0}(n+1)x^n.
```

一方

```math
(1-x)A(x)=a_0+\sum_{n\ge1}(a_n-a_{n-1})x^n.
```

係数比較より $`a_0=1`$、$`a_n-a_{n-1}=n+1\ (n\ge1)`$。ゆえに

```math
a_n=1+\sum_{k=1}^n(k+1)=\sum_{k=0}^n(k+1)=\frac{(n+1)(n+2)}2.
```

□

**学習記録：** 初回提出の漸化式による証明は正しいが、設問指定のコーシー積を直接使っていなかった。追加課題で指定手法による証明も完了した。

## Q8：制約付き非負整数解の総合問題

### 問題
$`a+b+c=n`$、$`a\ge0`$、$`0\le b\le2`$、$`c\ge0`$ を満たす非負整数組 $`(a,b,c)`$ の個数を $`N_n`$ とする。(1) 通常型母関数を求めよ。(2) 有理関数で表せ。(3) $`N_n`$ を $`n`$ の式で求めよ。(4) 全ての $`n\ge0`$ で成立することを証明せよ。形式的冪級数の演算を正当化すること。

### 解答（提出で用いた漸化式と帰納法）
$`a,c`$ は非負整数全体、$`b`$ は $`0,1,2`$ のみを動くので

```math
F(x)=\left(\sum_{a\ge0}x^a\right)(1+x+x^2)\left(\sum_{c\ge0}x^c\right)=\frac{1+x+x^2}{(1-x)^2}.
```

従って

```math
(1-2x+x^2)F(x)=1+x+x^2.
```

$`F(x)=\sum_{n\ge0}N_nx^n`$ として係数比較すると

```math
N_0=1,\qquad N_1-2N_0=1,\qquad N_2-2N_1+N_0=1,
```

および $`n\ge3`$ で

```math
N_n-2N_{n-1}+N_{n-2}=0.
```

よって $`N_1=3,N_2=6`$。$`n\ge1`$ に対し $`N_n=3n`$ を示す。$`n=1,2`$ で成立。$`n\ge2`$ とし $`N_n=3n`$、$`N_{n-1}=3(n-1)`$ を仮定すると

```math
N_{n+1}=2N_n-N_{n-1}=6n-3(n-1)=3(n+1).
```

従って数学的帰納法により $`N_n=3n\ (n\ge1)`$。$`N_0=1`$ は別に扱う。結論は

```math
\boxed{N_n=\begin{cases}1&(n=0),\\3n&(n\ge1).\end{cases}}
```

□

### 検算（直接係数を求める別解）
Q6より

```math
F(x)=(1+x+x^2)\sum_{m\ge0}(m+1)x^m.
```

$`n=0`$ では $`N_0=1`$。$`n=1`$ では $`N_1=2+1=3`$。$`n\ge2`$ では

```math
N_n=(n+1)+n+(n-1)=3n.
```

一致する。

**学習記録：** 添削中に一般式 $`3n`$ を誤りとする記述があったが、すぐに訂正され、提出された一般式と帰納法は正しいと判定された。
