# Vim による文字列置換

## 基本操作

```vim
:s/old/new/
```

| コマンド | 置換対象 |
| --- | --- |
| `:s/old/new/` | 現在行の最初の一致 |
| `:s/old/new/g` | 現在行のすべての一致 |
| `:%s/old/new/g` | ファイル全体 |
| `:%s/old/new/gc` | ファイル全体（逐一確認） |

## 範囲選択して置換する

1. `V` で行単位のビジュアルモードに入る。
2. `j` / `k` で範囲選択する。
3. `:` を押す。
4. `s/old/new/g` を入力する。

```vim
:'<,'>s/old/new/g
```

文字単位の選択範囲に限定する場合は `\%V` を使用する。

```vim
:'<,'>s/\%Vold\%V/new/g
```

## 区切り文字の変更

パスなど `/` を含む文字列を置換する場合は、区切り文字を変更できる。

```vim
:%s#/usr/local/bin#/usr/bin#g
```
